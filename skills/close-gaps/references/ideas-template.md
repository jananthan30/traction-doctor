# CLOSE-GAPS.md Template

Write to the analyzed repo's root (see SKILL.md → Phase 0 for the naming
and archive rules). Replace every angle-bracket slot. Keep the file under
~300 lines. The run date is the UTC date the run started (`date -u +%F`);
cite every other date as its source gives it. Cite repo evidence as
`path:line` and web evidence as links.

The `<!-- cg: … -->` line is the machine-readable record of this run: one
line of JSON inside an HTML comment, invisible on GitHub.
`scripts/check_ideas.py` checks that it agrees with the file. Keys: `v`
(plugin version), `date` (UTC run date), `mode` (`parallel` /
`generic-subagents` / `sequential`), `web` (true when research ran),
`report` (the source report's `date`, `bigness` and `moat`, from its `dg`
line), `targets` (the researched target ids, in Weakness order), `top` (the
Top ideas rows in order: `id`, `score`, `kind`, `build`).

Filling it:

- **Weakness sections** follow `cg.targets` order, with 2–3 cards each.
  When no idea survives for a target, write one line instead of cards:
  "No practical fix found: <why>".
- **Empty tables** (nothing structural, nothing cut) keep their header and
  one row reading `none`.
- **No research targets** (every weak point is a known fix or structural):
  `targets` and `top` are `[]`, there are no Weakness sections, *Top ideas*
  says so in one line, and *Do this first* is the first *Just do it* row.
- **Local-only run:** every Weakness section opens with
  `NOT RESEARCHED — re-run with web access`, and every card is `reasoned`
  with Proof 1, citing a distribution-god playbook section
  (`references/<file>.md`) instead of a link.
