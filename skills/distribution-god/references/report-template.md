# STRATEGY.md Template

Write to the analyzed repo's root. Replace every angle-bracket slot; delete
sections only if a phase was explicitly skipped. Keep the whole report under
~400 lines — density over volume. Cite repo evidence as `path:line` and web
evidence as links.
