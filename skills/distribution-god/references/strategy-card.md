# Strategy Card — shareable verdict infographic

After writing STRATEGY.md (Phase 5), also generate `assets/strategy-card.svg`
in the analyzed repo unless the user declined. The card is the report's
social artifact: README-embeddable (GitHub renders SVG natively), postable,
and it carries the fingerprint — this is the distribution loop of the tool
itself, so generate it by default.

Then:
1. Add `![Strategy card](assets/strategy-card.svg)` directly under the
   `## Verdict` heading in STRATEGY.md.
2. Suggest (don't force) embedding it in the repo's README.
3. If Google Chrome exists locally, offer a PNG twin for social posts
   (Reddit/X don't take SVG):
   `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless
   --disable-gpu --screenshot=assets/strategy-card.png --window-size=1200,1500
   --force-device-scale-factor=2 --hide-scrollbars <file-url-of-svg>`

## Fill rules (violating these breaks the layout — SVG text does not wrap)

- Replace every `{{SLOT}}`; keep everything else byte-identical, including
  colors — the palette is validated for contrast and colorblindness. Text
  stays in ink colors; only meters carry hue.
- Char limits: `{{PRODUCT}}` ≤ 24 · `{{TAGLINE_A}}`/`{{TAGLINE_B}}` ≤ 78 each ·
  `{{BIG_BAND}}` ≤ 46 · `{{BIG_NOTE}}`/`{{MOAT_NOTE}}` ≤ 60 · `{{MOAT_BAND}}` ≤ 34 ·
  `{{CRUX_A/B/C}}` ≤ 72 each · breakdown labels ≤ 22 · `{{CH_A/B/C}}` and
  `{{KILL_A/B/C}}` ≤ 44 each · `{{INSTALL}}` ≤ 46 · `{{REPO_URL}}` ≤ 44.
  Too long? Shorten the words, never the font size.
- Meter widths: bigness fill `{{BIG_W}}` = round(430 × score/25); moat fill
  `{{MOAT_W}}` = max(14, round(430 × score/25)). Breakdown fills `{{R1_W}}`…
  `{{R5_W}}` = round(560 × subscore/5). Sort breakdown rows descending.
- `{{VERSION}}` = plugin version; `{{DATE}}` = ISO date. The footer fingerprint
  line must keep the exact string `Generated by distribution-god` — it is the
  measurement hook.
