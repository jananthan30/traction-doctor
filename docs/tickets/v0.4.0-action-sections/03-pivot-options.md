# 03: Pivot options

**What to build:** section 9 becomes *Kill criteria and pivot options*.
Every v0.4 report offers 1–3 pivots from Ries's ten types (at least 2 when
the moat is *Nothing defensible yet* or Bigness ≤ 13), each keeping a named
asset, unlocking a named moat power, with a precedent, an ESTIMATE re-score,
a ≤5-day test with a pass line, and the kill criterion that triggers it,
plus a *Persevere if* line. A pivot playbook teaches the strategist; the red
team attacks pivot realism; the checker enforces the card contract.
